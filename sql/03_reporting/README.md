# REPORTING Layer

BI-ready views built on top of STAGING, in `01_reporting_views.sql`:

- `DAILY_SALES` — revenue and margin rolled up by order date.
- `CUSTOMER_SALES` — revenue and margin by customer.
- `PRODUCT_PERFORMANCE` — revenue and margin by product.
- `RETURNS_SUMMARY` — return volume and refund amount by product.
- `DELIVERY_PERFORMANCE` — shipment cost and count by delivery status.
- `EXECUTIVE_KPIS` — single-row summary for a BI landing page.
